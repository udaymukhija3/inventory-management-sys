Data Engineering Demo

Inventory Event To Analytics Evidence

This project records an inventory mutation, publishes a Kafka event, computes inventory analytics, stores the result in Postgres and Redis, writes Parquet artifacts, and serves the latest state through a small API. This page exists to prove that flow happened.

Source: operational inventory writes Pipeline: Kafka consumer + ETL Outputs: tables, Redis, Parquet, API

Two Minute Story

  1. Record one inventory sale for the seeded focus SKU.
  2. Wait for the pipeline to consume and materialize the event.
  3. Inspect the latest run, DQ result, outputs, and preview rows.
  4. Use the links below for raw API, metrics, and monitoring proof.
