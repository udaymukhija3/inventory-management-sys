Inventory Management System

Operational writes → Kafka → analytics, in one demo

A Spring Boot inventory service records each stock movement and publishes an event. A Python ETL consumer reshapes those events into Postgres analytics, Redis cache, and Parquet files. This page proves the loop end-to-end.
